# Mon fichier

Wortschatztrainer für Französisch (Primarstufe) mit Karteikasten, Übungen und Spielen.

- Läuft als einzelne Datei `index.html` im Browser, ohne Konto und ohne Mailadresse für Kinder.
- Der Fortschritt der Kinder wird nur im Browser des Geräts gespeichert.
- Wortlisten, Klassencodes und PIN stecken in `index.html`. Nach Änderungen im Bereich für Lehrpersonen unter «App-Datei» eine neue `index.html` herunterladen und hier ersetzen.

Status: Testversion.
